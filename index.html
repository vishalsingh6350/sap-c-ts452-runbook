Before you start
The silent killers — fail at evaluation, look fine on screen
  1. Source Determination left ON when creating a requisition (Tasks 3.6, 4.1) — the source appears by itself and the "assign source" step proves nothing.
  2. Plant created with New Entries instead of Copy org. object (Task 3.1) — the plant exists and carries none of the dependent assignments.
  3. Business Partner saved without the Company Code / Purchasing Org segments (Task 3.4) — the BP exists, the vendor does not.
  4. Flexible workflow saved but never activated (Task 3.8) — looks saved, never runs.
  5. Purchase order created standalone instead of from the requisition (Tasks 3.9, 4.3) — the link is graded.
  6. Invoice posted instead of parked (Task 4.6) — the park itself is graded.
  7. Tolerance group created after the invoice (Task 5.6 vs 5.7) — automatic reduction is only evaluated at posting time.
  8. FI tolerance group missing (Task 5.6a) — the supplier master rejects the group with a T043G error. This is the prerequisite the exam text never mentions.
  9. SC Vendor not set on the component order (Task 5.2) — the receipt lands in plant stock, not vendor stock.
  10. Requisition not set to Fixed (Task 7.6) — the next MRP run eats it.
  11. German description not maintained on the product master (Task 3.3) — it hides behind Additional Data → Descriptions.
  12. Wrong document type. ZNBF in Task 3.9; NB in Tasks 4, 5, 6. It cannot be changed after the first item.
  13. Output record created but never processed. It must read Successfully processed.
